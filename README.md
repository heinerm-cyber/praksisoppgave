# praksisoppgave
jeg har laget en pris kalkulator for en pizza bestiling 

du starter koden ved og trykke på play tegnet som ligger oppe til høgre i visual studio code 

når koden starter vil bestilingen starte da skrives det ut ett spørsmål i terminalen som spør om hvilken type bun du vil ha på pizzaen og hvilken type bunner du kan velge mellom. 
Hvis du er uheldig og skiver feil har jeg brukt while løkker under alle spørsmålene som gir deg mulighet til og velge på nytt hvis du har skrevet feil.

underveis mens du bestiller etter hvert av spørsmålene vil koden også printe ut hva prisen på pizaen er midlertidig også på slutten av koden vil den oppsummmere helle prisen 

i denne branchen er koden er den satt op med if og elif i stede for dictionary men den funker på helt samme måtte som den andre jeg har også brukt while løkkker og for løkker til og la deg begynne på nytt og til og gå gjennom spørsmål
